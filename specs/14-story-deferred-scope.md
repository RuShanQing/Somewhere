## 1. 目的

[06-city-stories.md](06-city-stories.md) 仍是城市故事的 API、数据与审核合同。本文件只记录 TASK-005 **暂不实现**的授权开关与产品假设，避免出现以下问题：

- 把“未实现”写成“已支持”；
- 为了页面完整而放置没有真实效果的开关；
- 以后补做时绕过审核、迁移或权限测试；
- 把“隐藏个人资料城市”误当成“故事匿名”。

## 2. TASK-005 当前合同

TASK-005 只实现以下范围：

- 作者可以保存 `DRAFT`、编辑 `DRAFT/REJECTED`、提交为 `PENDING`；已提交内容不能直接改写；
- 作者发布故事时必须显式选择静态城市目录中的城市；公开故事展示该城市；
- 公开条件：`review_status = APPROVED AND published_at IS NOT NULL AND archived_at IS NULL AND public_consent_at IS NOT NULL`；
- 标题 1–80 字符、正文 20–3000 字符、主题标签最多 3 个；
- 每城市最多 50 条活跃故事；每账号每 7 天最多提交 3 条新稿（具体数值仍以 06 为准）；
- 审核角色为 `ADMIN`，审核动作仅 `APPROVE / REJECT / REMOVE`，操作写入审计；
- 不按点赞、浏览量、粉丝量或社交热度排序；
- 公开作者只显示昵称，不显示邮箱或城市坐标。

PRD 中“标题 ≤40 字”“正文 80–400 字”“每用户 2 条展示中”“30 天展示窗口”“每天最多 24 张”等属于产品建议值，**不是 TASK-005 的合同**；是否调整为 06 的数值，留到后续任务重新评估。

## 3. 暂不实现的能力

| 能力 | TASK-005 的实际行为 | 后续实现的前置条件 |
|---|---|---|
| 显示城市开关 | 不新增字段、不渲染开关；作者在发布时选择城市，公开故事展示该城市 | 需迁移 `show_city`、公开 DTO、城市筛选的推断防护、作者撤回授权、06/03 同步与 E2E |
| 上地图开关 | 不新增字段；世界记忆地图页面未实现 | 需先完成 07 的地图业务入口，并同时校验“作者授权 + 审核通过”；两个入口共用 `ApprovedStoryReader` |
| 接受共途邀请开关 | 不新增字段；共途与邀请流程未实现 | 需先完成 09 的双方同意、邀请限额、封锁优先与拒绝/忽略流程 |
| 匿名作者 / 匿名标识 | 不实现；公开故事显示 `users.nickname` | 需定义匿名授权、显示名策略、审核与滥用防护，并更新 06/03 |
| 30 天展示窗口 | 不实现自动归档；仅使用 `archived_at` 记录撤回/下架 | 需确定定时任务或查询策略、作者可见状态、容量轮换与测试；更新 06 |
| 每日 24 张轮播 | 不实现；公开列表按发布时间游标分页 | 需确定“每日”时区、轮换算法、缓存与可解释性；不得按热度排序 |
| 每用户 2 条展示中 | 不实现；只限制每城市活跃容量与提交频率 | 需定义“展示中”的统计口径、排队与释放规则；更新 06 |
| 点赞 / 浏览 / 粉丝 / 热度榜 | 永久不进入故事站范围 | 无；产品明确不以社交热度组织内容 |
| 用户公开主页 | 不实现；故事详情只展示作者昵称 | 需单独的资料可见性规范与授权模型 |

## 4. 安全与实现约束

1. **不得伪造开关。** 未实现的授权能力不能出现在发布表单或详情页中；不能显示可点击但无效果的按钮。
2. **不得用“未实现”代替“默认公开”。** 暂缓项的行为是“能力不存在”，不是“默认开启”或“默认关闭”。
3. **地图必须复用故事数据源。** 未来地图只能通过同一个 `ApprovedStoryReader` 和同一 `Story ID` 读取；本阶段公开 API 的 `cityId` 筛选是未来地图的唯一数据入口，不新增“地图故事”实体。07 中列出的 `/cities/:id/stories` 若保留，只能是同一 Reader 的薄别名，不能形成第二套查询或可见性规则。
4. **任何开关都要全链路实现。** 后续补做时必须同时完成：数据库迁移、DTO、OpenAPI、客户端生成、契约测试、权限测试、E2E、06/07/09 文档同步；禁止只改前端。
5. **隐藏个人资料城市 ≠ 故事匿名。** 06 中“作者可以隐藏个人城市信息”属于资料可见性能力，TASK-005 不实现；TASK-005 的发布流程要求作者显式选择并公开故事城市。后续隐私任务需要把两者分开建模，不能用同一个字段混用。

## 5. 验收边界

TASK-005 的验收不得声称以下能力已经可用：

- 显示 / 隐藏故事城市；
- 上 / 下地图；
- 接受 / 拒绝陌生共途邀请；
- 匿名作者；
- 30 天自动归档、每日轮播、每用户展示条数上限；
- 点赞、浏览、热度、公开主页。

TASK-005 可以验收的是：作者写作与提交、管理员审核、公开故事站与详情、撤回/下架同步消失、城市容量与提交频率、作者与管理员权限隔离。
